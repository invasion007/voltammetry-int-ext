# 伏安法测电阻 · 内接与外接 · 可交互课件

人教版高中物理《伏安法测电阻》配套可视化：把「内接法 / 外接法怎么选、误差从哪来」做成可以拖着看的课件。

在线打开：<https://invasion007.github.io/voltammetry-int-ext/>

## 这一课解决什么

1. **误差不来自"读数读错了"**，而来自"表自己也在电路里"：电流表有内阻 R_A 会分压，电压表有内阻 R_V 会分流。
2. **内接法**：电压表跨在「Rₓ + 电流表」上 → 多读了 I·R_A → R测 = Rₓ + R_A，**恒偏大**，δ内 = +R_A/Rₓ。
3. **外接法**：电流表在电压表外面 → 多读了 U/R_V → R测 = Rₓ∥R_V，**恒偏小**，δ外 = −Rₓ/(Rₓ+R_V)。
4. **怎么选**：两条误差曲线相交处 R₀ ≈ √(R_A·R_V)。**大内小外**（Rₓ > R₀ 用内接，Rₓ < R₀ 用外接）。
5. **不知道 Rₓ 多大**：试触法。严格恒等式 ΔU/U ÷ ΔI/I = R_s/(Rₓ∥R_V)，哪个表示数变化大就避开它对应的那种接法。

## 画面怎么读

| 位置 | 内容 |
|---|---|
| 左上电路 | 真实接法。红框 = 电流表"多读"的那一段，蓝箭头 = 电压表"分走"的那一路 |
| 右上标尺 | 两种接法的 δ 同屏对比（对数刻度 0.01%→100%），并给出"该用哪种" |
| 右下曲线 | 红线 δ内 ∝ 1/Rₓ、蓝线 δ外 ∝ Rₓ，交点就是 R₀ |
| 底部读数行 | U读、I读、R测 = U/I、Rₓ 真值 |
| 分解条 | 把读数拆成"真值那一段 + 多读的那一段"，直观看出误差来源 |
| 右栏 | 这一刻的读数 / 两只表的内阻 / 结论 / 白话解释 / 公式 |

## 可拖可换

- 拖画布底部黄色圆点或底栏滑杆：**Rₓ**（对数 1 Ω ~ 5 kΩ）
- 底栏「换表头」：三套表头（10 mA/10 Ω、1 mA/30 Ω、50 μA/200 Ω）→ R_A、R_V、R₀ 全部跟着变
- 「真表 / 理想表」：切到理想表（R_A=0、R_V=∞）看误差归零
- 键盘 ← → 翻步，Home / End 到头，数字键 1~3 换表头
